# Thèmes visuels

Le thème actif est `theme-farever.css`, chargé par `index.html` et `farever-report.html`.

Pour revenir à l’ancienne apparence sombre, remplacer dans les deux pages :

```html
<link rel="stylesheet" href="css/theme-farever.css">
```

par :

```html
<link rel="stylesheet" href="css/theme-night.css">
```

Le HTML et le JavaScript ne changent pas : seuls les styles sont remplacés.
